## 🔧 Instructions d'Utilisation

### Étapes de Génération :

1. **Choisir la Plateforme**
   - Canva : Pour design visuel attractif
   - Gamma : Pour génération IA complète
   - ChatGPT/Claude : Pour contenu détaillé
   - Beautiful.AI : Pour design automatique intelligent
   - Google Slides : Pour collaboration et simplicité

2. **Personnaliser le Prompt**
   - Remplacer [Votre Nom], [Université], etc.
   - Adapter les métriques à votre projet
   - Ajuster le niveau technique selon le jury
   - Modifier la durée selon les contraintes

3. **Itérer et Améliorer**
   - Générer une première version
   - Réviser avec les prompts d'amélioration
   - Tester avec des collègues
   - Affiner selon les retours

4. **Finaliser**
   - Vérifier la cohérence visuelle
   - Pratiquer la présentation
   - Préparer les réponses aux questions
   - Créer des slides de backup

### Conseils d'Optimisation :

- **Spécificité** : Plus le prompt est détaillé, meilleur est le résultat
- **Itération** : Utilisez les résultats pour affiner les prompts suivants
- **Combinaison** : Mélangez les approches (contenu IA + design manuel)
- **Validation** : Faites réviser par des experts du domaine
- **Backup** : Gardez plusieurs versions et options
