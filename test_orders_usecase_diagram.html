📋 Diagramme de Cas d'Usage des Commandes

🎯 ZAI E-commerce Features

  • Client Functions: Create orders, process payments, view history, track status
  • Address Management: Manage shipping addresses, apply discount codes
  • Order Control: Cancel orders, request refunds
  • ZAI Admin: Validate orders, update status, generate invoices, process refunds
  • Returns Management: Handle product returns and exchanges
  • Dolibarr Integration: Sync customer data, update stock, generate invoices, track shipments

📝 Instructions de Génération

Option 1 - Service en ligne (Recommandé):

PlantUML Online Server PlantUML Editor

Option 2 - Installation locale:

  1. Installer Java JRE 8+
  2. Télécharger plantuml.jar
  3. Exécuter: java -jar plantuml.jar -tpng plantuml_orders_usecase_diagram.puml

Option 3 - Extension VS Code:

Installer l'extension "PlantUML" et utiliser Ctrl+Shift+P → "PlantUML: Preview Current Diagram"
