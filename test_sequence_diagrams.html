Instructions pour générer les images PNG :

  1. Copiez le code PlantUML de chaque diagramme
  2. Allez sur PlantUML Online Server
  3. Collez le code dans l'éditeur
  4. Téléchargez l'image PNG générée
  5. Renommez le fichier selon le nom indiqué
  6. Placez le fichier dans le répertoire du projet ZAI
